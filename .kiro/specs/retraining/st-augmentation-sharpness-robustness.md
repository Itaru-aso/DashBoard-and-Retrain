# monochro ST側augmentation拡張（sharpen/blur・撮像環境ドリフト頑強性） v1.0

> 位置づけ: `retraining` spec の `design.md` を上書きせず、学習時augmentationの拡張に関する
> 意思決定記録（ADR）として独立管理する。CLAUDE.md「学習ロジック変更不可」への
> **追加承認済み例外**（2026-08-05 ユーザー承認）。

## 目的 / 背景

2026-08-03 に配信した 567 monochro モデルが実機で全数NG（虚報）となった。分析の結果、
原因は**照明の新品交換＋カメラ・照明の再取り付け**に伴う撮像ドメインシフトであり、
学習データと実機画像の間に以下の差が実測された（分布の重なりなし）:

| 指標 | 学習データ | 実機（交換直後） |
|---|---|---|
| 輝度mean | ≈131（p1≈26, p99≈209） | ≈125（p1≈16, p99≈196） |
| シャープネス（Laplacian分散） | 391〜469（mean≈435） | 202〜368（mean≈308） |

物理調整（照度9段階・ピント16段階の切り分け実験）の結果:
- 照度460が最適（NG率72.7%）だが、以降のピント調整で一度NG率15%（設定E, sharp≈413）を達成後、
  **同一設定に物理的に戻せない**ことが判明（再現性なし）。
- 最終的に再現可能な設定P（sharp≈639、学習データの約1.47倍鮮明）を新標準とする方針を採用。
- 補正実験: per-image mean/std 線形輝度補正では虚報は解消しない（複合的な画質差のため）。

今後の**台数展開・照明経年劣化・保守時の再取り付け**でも同種のドメインシフトが想定されるため、
モデル側に撮像画質（シャープネス方向）の頑強性を持たせる。

### 技術的前提（コード調査で確認済みの事実）

- 異常スコアの主体は **ST（teacher-student）ブランチ**。既存の `pre_tf`（brightness/blur等の
  augmentation）は **AEブランチにのみ**適用され、STブランチには届かない
  （`training/train/common.py` の `TrainTransform.__call__`）。
- STブランチには `st_augmentation`（config-gated）が既に存在するが、
  対応は horizontal_flip / ColorJitter（brightness・contrast・saturation）のみで、
  **シャープネス方向（blur/sharpen）の augmentation は存在しない**。
- 閾値・quantile（q_st）・teacher再正規化・cand1（μ,σ,A,Z）の較正は validation_loader 経由で
  st_tf 適用後の画像に対して行われるため、st_augmentation の拡張は較正側にも自動的に反映される
  （良品スコア分布が広がる → 閾値がその分保守的になる）。

## 決定事項

1. **対象は monochro のみ**。color は現状問題が観測されていないため適用しない。
   `st_augmentation` は mode 別 config セクションのため、monochro セクションにのみ
   新キーを設定することで自然にスコープされる（コード自体は共通だが、既定値は無効）。
2. **追加する変換は sharpen（鮮明化）と blur（ボケ）の両方向**（2026-08-05 ユーザー選択）。
   - sharpen が本命: 新標準P環境（1.47x鮮明）および将来のより鮮明な号機への対応。
   - blur は保険: 照明経年劣化・軽微なピントズレ（今回のボケ側実測 170〜290）への対応。
3. **実装場所**: `training/train/common.py` の `get_st_transform()` に config-gated で追加。
   - sharpen: カスタムクラス `RandomSharpness(factor_min, factor_max, p)` を同ファイルに追加
     （`TF.adjust_sharpness` を factor一様乱数で適用。torchvision 標準の
     `RandomAdjustSharpness` は factor 固定のため連続範囲をカバーできない。
     Windows multiprocessing 対応のため pickle 可能なクラスとして定義し、Lambda は使わない）。
   - blur: torchvision 標準 `RandomApply([GaussianBlur(kernel_size=5, sigma=(0.1, sigma_max))], p)`。
4. **config キー**（`st_augmentation` セクション内・すべて既定で無効=後方互換）:
   | キー | 既定 | monochro設定値 | 根拠 |
   |---|---|---|---|
   | `sharpen_p` | 0（無効） | 0.3 | 無変換の画像も学習に残す |
   | `sharpen_factor_min` | 1.0 | 1.0 | 無変換〜連続的にカバー |
   | `sharpen_factor_max` | 2.0 | 2.0 | 実測較正: factor1.5→1.62x（P=1.47xをカバー）。2.0→2.41xで将来のより鮮明な環境への余裕。感度低下が出た場合の第一縮小候補 |
   | `gaussian_blur_p` | 0（無効） | 0.3 | 同上 |
   | `gaussian_blur_sigma_max` | 0.6 | 0.6 | 実測較正: sigma0.5→0.51x(sharp≈219)。ボケ側観測(170〜290)をカバー |
   - 較正実測（学習ドメイン80half, 2026-08-05）: base mean=429 / sharpen 1.25→1.29x, 1.5→1.62x,
     2.0→2.41x / blur σ0.3→1.00x, σ0.5→0.51x, σ0.8→0.19x。
5. **sharpen と blur は独立の RandomApply**（排他にしない）。同時適用は p²=9% で打ち消し方向に
   働くが、実害は軽微であり、RandomChoice による排他化はコードを複雑にするため採用しない。
6. **検証は2ステップ**（ユーザー指定の計画）:
   - **ステップ1（ドメインシフト対応の効果検証・567）**: 通常データ
     （`export_root`/`export_root_margin` の 567、旧照明ドメイン）で aug 適用の学習を実施。
     従来評価に加え、**P環境実機データ**（`C:\Users\0032011\Downloads\image\567\val`、
     good 348枚/defect 1枚）で新旧モデルのスコア・NG率を比較。
     成功基準: P環境 good の NG率が現行モデル（cand1_T=1.0 で約45〜53%）から有意に低下すること。
   - **ステップ2（不良品感度の非劣化検証・181）**: 181 を aug 適用で再学習し、
     aug適用前モデル（`training/6_model/181/05_CZT8_/monochro`）と不良品感度を比較。
     181 monochro NG 10枚（`export_root` 通常側）で両モデルのスコアを比較し、
     感度（スコアの閾値比・分離度）が低下していないことを確認。良品側FPも併せて比較。
     成功基準: NG画像のスコア/閾値比が旧モデルと同等以上（明確な劣化がない）。
   - 感度低下が観測された場合: `sharpen_factor_max` を 2.0→1.75→1.5 と縮小して再実験
     （blur/sharpen の切り分けが必要な場合は1つずつ無効化して原因特定）。
7. **本ADR確定後の恒久設定**: ステップ1・2 とも合格した場合、monochro の `st_augmentation`
   新キーを config.yaml の標準値として恒久化する。以降の全 monochro 再学習に適用される。

## 却下した代替案

- **blur のみ追加（当初案）**: P環境は学習データより鮮明側のため、blur だけではステップ1の
  検証目的（P環境対応）に合致しない。却下（2026-08-05 ユーザー確認済み）。
- **実機側での輝度・画質後処理補正**: per-image mean/std 線形補正の実験で虚報が解消しないことを
  確認済み。ボケ/鮮明の後処理補正は不確実性が高く不採用。
- **model.py の正規化方式変更（per-image適応正規化）**: モデル構造の変更にあたり
  CLAUDE.md の変更不可領域。ONNX にベイクされる正規化と学習側の不整合リスクも大きい。不採用。
- **AE側 pre_tf の流用・強化**: AEブランチは異常スコアの主体ではなく、ST側に届かないため
  目的に対して無効。不採用。
- **号機ごとの閾値較正のみで対応**: 有効な補完策（設置時に良品N枚で閾値較正）だが、
  モデル自体の頑強性がないと較正しても分離マージンが薄い。augmentation と併用が望ましい
  （閾値較正の標準化は別タスクとして扱う）。

## 制約 / 非目標

- **color 側の学習ロジック・augmentation は変更しない**（config も color セクションは触らない）。
- 損失関数・モデル構造・学習ループ本体は変更しない（変更は `get_st_transform` と
  カスタム変換クラスの追加のみ）。
- 今回級の大シフト（輝度mean 125→160級）を augmentation で吸収することは目標としない。
  それは撮像環境の物理調整＋新ドメインでの再学習が担う。augmentation は±小ドリフトの保険。
- 撮像系ヘルスチェック（保守後の基準統計照合）・号機別閾値較正の運用標準化は別タスク。

## 検証基準（ゲート）

- 単体テスト: `get_st_transform` の新キー gating（既定=無効で従来と同一変換列/有効時に適用）が green。
- ステップ1: P環境 val good 348枚で新モデルの NG率 < 現行モデルの NG率（有意な改善）。
  旧ドメイン（従来評価）の閾値・良品スコアが破綻していないこと。
- ステップ2: 181 NG 10枚のスコア/閾値比が旧モデル比で劣化なし。良品FP同等以下。

## 系統的パラメータ探索の実験計画（v1.1 追記）

### 評価スコープ（2026-08-05 ユーザー確定）

- **評価対象は `567/val` のみ**（good 348枚 / defect 1枚）。撮像環境評価用に取得した
  照度軸8フォルダ・ピント軸15フォルダは**本検証から除外**する。
- P環境での判定は**良品の誤検知(FP)のみ**。実欠陥の追加取得は不可のため、
  **P環境（新ドメイン）での欠陥検知性能は本検証では確認できない**（残存リスク）。
- 感度の非劣化判定は **181 の実NG 10枚（旧ドメイン）** で行う。

### 設計原則: 最小有効量

FP目標を満たす**最も弱いaug設定**を採る。新ドメインでの感度が検証不能である以上、
「念のため強めに」は検証できないリスクを増やすだけであるため採らない。

### 前処理の取り扱い（実装上の重要事項）

データ源によって前処理が異なる。混同すると評価値が無意味になる（実際に初回測定で
二重cropの誤りが発生し、181 NG のスコアが 1.78→2.30 と過大に出た）。

| データ源 | 実寸 | 必要な前処理 |
|---|---|---|
| `val/`（実機raw） | 2048×1220 | `process_image`（crop 485+1250 → top/bottom分割 → resize）。per-image max で判定 |
| `export_root/`（181 NG等） | 1250×670 | **resize のみ**（crop・分割済み）。1ファイル=1半面 |
| `export_root_margin/`（学習用） | 2048×1220 | `RawShiftImageFolder` が内部で crop |

### 統計上の制約と対策

`val/good` 348枚は **80秒間の連続撮像**（約4.3枚/秒）であり、実質的な独立標本数は
348より大幅に小さい。単一キャプチャへの過学習を避けるため:

- **時間ブロックで前半174枚（選抜用）/後半174枚（確認用）に分割**する（ランダム分割は
  隣接フレームがほぼ同一のため不可）。構成の選抜は前半のみで行い、最終確認は後半で行う。
- 比較する構成数を絞る（Phase Bで6構成程度）。
- 改善幅がノイズフロア（Phase A3で実測）を明確に超えることを要求する。

### 探索対象パラメータの優先度（`ae_para=0` の実測に基づく）

monochro のスコアは **ST分岐のみ**で決まる（config `map_ae: 0.0`、実測で567・181とも
`para.json: ae_para=0.0`。`compute_anomaly_score` は `ae_para>0` のときのみAE分岐を加算）。

| 群 | スコアへの経路 | 優先度 |
|---|---|---|
| `st_augmentation`（sharpen / blur / brightness / contrast） | ST入力分布を直接変える | **高** |
| `penalty_augmentation` | penalty損失経由で map_st の挙動を形成 | 中（316で4/4悪化の前例） |
| `augmentation.monochro.ae_*` | AE分岐＝**スコア重み0**。student trunk共有(loss_stae)経由の間接影響のみ | 低 |

### 実験サイクルの高速化（P1）

- 実験は **monochro単独**・データセット再利用（`train_monochro` を直接呼ぶ scratchpad
  スクリプト方式。316実験と同一）。567 monochro は margin データを毎回 `export_root_margin`
  から読むため `4_dataset` の再構築は不要。
- スクリーニングは `monochro.max_train_step 30000→10000`（フル長は margin 1942枚×2半面の
  70%＝2718サンプル / batch4 → 679 iter/epoch × 50ep = 33,950 を 30,000 にcap）。
- seed変更は `train.monochro.seed`（モジュール定数）の実行時上書きで行う（コードは変更しない）。

## 実験結果

### C0: フル長・sharpen+blur 両方（job21・2026-08-05）

`sharpen_p 0.3 / factor 1.0-2.0 + gaussian_blur_p 0.3 / sigma 0.1-0.6`、
`max_train_step=30000`（フル長）。**ベースラインと同一学習長のため直接比較可能。**

| 指標 | ベースライン（aug無し） | C0（aug両方） | 差 |
|---|---|---|---|
| val/good NG率 全体 | 84.5% | **27.3%** | **−57.2pt** |
| 　前半（選抜） | 85.6% | 29.3% | −56.3pt |
| 　後半（確認） | 83.3% | **25.3%** | **−58.0pt** |
| val/good P95 | 1.593 | 1.277 | −0.316 |
| val/defect（n=1・参考） | 1.578 検知 | 1.253 検知 | 検知維持 |
| 181実NG 検知率 | 100%（10/10） | **100%（10/10）** | 維持 |
| 181実NG median | 1.784 | 1.597 | −0.187 |
| **分離マージン** | 1.120 | **1.251** | **+0.131（改善）** |

**判定: ゲート G-C を全項目クリア。**

1. val/good 後半 25.3% ≪ 83.3% − T（改善58ptはいかなるノイズフロアも大幅に超える）
2. 181実NG 検知率 100% を維持
3. 分離マージン 1.251 ≥ 1.00

**重要な所見**: 分離マージンが**改善**した（1.120→1.251）点が本質的である。
「augで良品分布が広がり閾値が上がった結果、FPが下がっただけ（＝感度も一緒に鈍った）」
のであればマージンは横ばいか悪化するはずだが、実際には**良品P95の低下幅（−0.316）が
NG中央値の低下幅（−0.187）より大きい**。つまりモデルはシフト後ドメインで
**単に寛容になったのではなく、識別性そのものが向上している**。

**残る課題**: FP 27.3% は改善幅は大きいが**本番水準（目安 <5%）には届いていない**。
augmentation単独ではドメインギャップを埋めきれず、当初の分析どおり
「主対策＝P環境での再学習／aug＝将来の小ドリフトへの保険」という位置づけが妥当である。
Phase B で最小有効量と強化方向の余地を確認する。

### Phase A: 検証基盤（短縮学習 max_train_step=10000・各48分）

| tag | seed | val前半 | 181検知率 | 分離M |
|---|---|---|---|---|
| A2_noaug_s42 | 42 | 43.7% | 100% | 1.138 |
| A3_noaug_s99 | 99 | 44.8% | 100% | 1.098 |

  短縮 43.7%→20.1%（−23.6pt）。効果の方向と有意性は保存されている
  （短縮学習の絶対NG率はフル長より低く出るため、構成比較は短縮ベースラインA2基準で行う）

| B2 | blur(p.3, σ0.1-0.6) | 25.9% | −17.8 | 100% | 1.122 | 検知 | ✅ |
| A2 | aug無し（基準） | 43.7% | — | 100% | 1.138 | 検知 | ✅ |

#### 決定的な所見1: brightness augmentation は感度を破壊する（棄却）

FPだけを見れば B6（1.7%）・B4（6.3%）が圧倒的に良く、**事前に感度ゲートを固定していなければ
B6を採用していた**。しかし実際には:

- B6: 181実NG **6/10 見逃し**、分離M 0.995（良品P95を下回る）、**P環境の実欠陥も見逃し**
- B4: 181実NG 1/10 見逃し、**P環境の実欠陥も見逃し**

**旧ドメイン（181）と新ドメイン（P環境の1枚）の双方で一致して感度低下が観測された**ため、
この棄却は確度が高い。

機序: 本用途の欠陥は「小さな黒点・薄い汚れ」＝**局所的な輝度異常**である。
`color_jitter_brightness/contrast` を±0.3まで広げることは、モデルに
**欠陥そのものと同種の変動を「無視すべきノイズ」として教える**ことに等しい。
FPが劇的に下がるのは欠陥を含む異常全般に鈍感になった結果であり、望む頑強性ではない。
→ **brightness/contrast の拡張は採用しない**（現行0.1を維持）。

#### 決定的な所見2: sharpen は強化するほど FP と感度が同時に改善する

| | val前半 | 分離M |
|---|---|---|
| B1: sharpen p0.3 / factor 2.0 | 23.6% | 1.197 |
| B5: sharpen p0.5 / factor 3.0 | **15.5%** | **1.442** |

通常 augmentation の強化は「FP改善／感度低下」のトレードオフになるが、sharpen では
**両方が改善している**（181実NGのスコアも B5 では 1.40〜1.81 と余裕がある）。
シャープネス変動は欠陥信号と直交する nuisance 変動であり、これを潰すことが
純粋に有益であることを示す。→ **強化方向にさらに余地がある可能性が高く、ラウンド2で追い込む**。

#### 選抜（事前ルール適用）

感度合格構成のうち Δ 最大は **B5（−28.2pt）**。B3との差 4.6pt は T=5.0pt 未満で
FPは統計的に同等だが、**B5の分離マージン（1.442）はB3（1.142）を明確に上回る**。
最小有効量の原則は「検証できない感度リスクを避ける」ためのものであり、
B5は感度が両ドメインで実測され、かつ優れているため、B5を第一候補とする。

### ラウンド2: sharpen強化方向の追い込み（短縮学習・各49分）

| tag | 構成 | val前半 | Δ vs A2 | 181検知率 | 分離M |
|---|---|---|---|---|---|
| **R2a** | **sharpen p0.7 / factor 1.0-4.0** | **9.2%** | **−34.5** | **100%** | **1.368** |
| R2b | sharpen p0.5/f3.0 + blur p0.3/σ0.6 | 8.0% | −35.7 | 100% | 1.246 |
| （参考）B5 | sharpen p0.5 / factor 1.0-3.0 | 15.5% | −28.2 | 100% | 1.442 |

- sharpen強化（B5→R2a）で FP 15.5%→9.2%（−6.3pt > T）。**強化方向はさらに有効だった**
- blur追加（B5→R2b）でも FP 15.5%→8.0%（−7.5pt > T）。blurも独立に有効
- R2a と R2b の FP 差 1.2pt は T=5.0pt 未満＝**統計的に同等**

**選抜: R2a**。理由は**分離マージン（10サンプル基準）が R2a 1.368 > R2b 1.246** であること、
および R2a が単一機序（sharpen のみ）で構成が単純であること。

#### 【自己修正】n=1 の欠陥スコアを判別材料に使ってはならない

当初 R2a/R2b の判別に「P環境 val/defect（n=1）の検知/見逃し」
（R2a=検知 1.040 / R2b=見逃し 0.916）を用いようとしたが、**全構成の値を並べた結果
これは誤りと判明した**。

| 構成 | P環境defect(n=1) | 181検知率 |
|---|---|---|
| ベースライン（フル長・aug無し） | 1.578 検知 | 100% |
| C0（フル長・sharpen p0.3+blur） | 1.253 検知 | 100% |
| A2（短縮・aug無し） | 1.082 検知 | 100% |
| B2（短縮・blurのみ） | 1.065 検知 | 100% |
| B5（短縮・sharpen p0.5/f3.0） | 1.064 検知 | 100% |
| R2a（短縮・sharpen p0.7/f4.0） | 1.040 検知 | 100% |
| B1（短縮・sharpen p0.3/f2.0） | 0.977 **見逃し** | 100% |
| B3（短縮・sharpen p0.3+blur） | 0.957 **見逃し** | 100% |
| R2b（短縮・sharpen p0.5/f3.0+blur） | 0.916 **見逃し** | 100% |
| B4（短縮・bright） | 0.853 **見逃し** | 90% |
| B6（短縮・sharpen+bright） | 0.722 **見逃し** | 40% |

**181検知率100%の構成では、n=1欠陥スコアは 0.916〜1.082 の範囲に散らばり、
aug強度と単調な関係を持たない**（B1 0.977 < B5 1.064 > R2a 1.040 で、sharpen強度順に
並ばない）。この欠陥は短縮学習の水準では閾値1.0の直上/直下に偶然落ちるだけであり、
**構成間の判別には使えない**。

一方、**brightness構成（B4 0.853 / B6 0.722）だけは明確に低く**、統計的に有意な
181の結果（90% / 40%）と一致している。したがって n=1 の値は
「大きく外れた構成の棄却を裏付ける補助証拠」としては有効だが、
**合格圏内の構成同士を分ける材料にはならない**。

なお全構成でフル長モデル（1.253〜1.578）は短縮モデル（〜1.08）より
欠陥スコアが明確に高い。感度の最終判断は**フル長（Phase C）で行うべき**である。

### Phase C: フル長確定（max_train_step=30000・各約117分）

全てフル長＝ベースラインと同一条件で直接比較可能。

| 構成 | val全体 | val前半 | **val後半(確認)** | goodP95 | 181検知率 | 181median | **分離M** | P-defect(n=1) |
|---|---|---|---|---|---|---|---|---|
| ベースライン（aug無し） | 84.5% | 85.6% | 83.3% | 1.593 | 100% | 1.784 | 1.120 | 1.578 検知 |
| **C0**: sharpen p0.3/f2.0 + blur p0.3/σ0.6 | **27.3%** | 29.3% | **25.3%** | 1.277 | 100% | 1.597 | 1.251 | 1.253 検知 |
| **C1**: sharpen p0.7/f4.0（blurなし） | 32.5% | 35.1% | 29.9% | 1.362 | 100% | **2.063** | **1.514** | 1.364 検知 |

（val後半 < 83.3% − T=5.0 ／ 181検知率100% ／ 分離M ≥ 1.00）。

#### 【重大な方法論的発見】短縮学習は構成間の順位を保存しない（G-Sゲートの不備）

| 構成 | 短縮(10000step) val前半 | フル長(30000step) val前半 | 順位 |
|---|---|---|---|
| aug無し | 43.7%（A2） | 85.6%（baseline） | 4位 → 4位 |
| sharpen p0.3+blur | 20.1%（B3） | **29.3%（C0）** | 3位 → **1位** |
| sharpen p0.5/f3.0 | 15.5%（B5） | 42.5%（C2） | 2位 → **3位** |
| sharpen p0.7/f4.0 | **9.2%（R2a）** | 35.1%（C1） | **1位** → 2位 |

短縮学習では「sharpenを強くするほど良い」という明確な単調傾向が出たが、
**フル長では逆転し、最も弱いsharpen＋blurのC0が最良となった**。

設定した G-S ゲートは「aug有無の**効果方向**が保存されること」しか検証しておらず
（これは保存された）、**構成間の順位保存は検証していなかった**。この不備により、
Phase C の候補選定（R2a・B5）が誤った根拠に基づいていた。

**教訓**: 短縮学習は「augが効くか否か」のスクリーニングには使えるが、
**構成間の優劣判定には使えない**。原因の推定として、短縮学習では student が
未収束であり、augによる正則化の効果が収束後とは異なる形で現れるため。
今後この種の探索では、**候補の絞り込みにのみ短縮を使い、優劣判定は必ずフル長で行う**。

#### 選抜の再検討

- FP（後半・確認用）: C0 25.3% < C1 29.9% < C2 40.2%。**C0とC1の差 4.6pt は T=5.0pt 未満
  ＝統計的に同等**。C2は明確に劣る（C0比 +14.9pt）
- 感度: **C1 が全指標で優位**（分離M 1.514 vs C0 1.251／181median 2.063 vs 1.597／
  P-defect 1.364 vs 1.253）
- 最小有効量の原則は「検証できない感度リスクを避ける」ためのものであり、
  感度が実測され C1 が優れている以上、C1 を機械的に「強すぎる」として退ける根拠はない

→ **C0（FP最良・blurあり）と C1（感度最良・blurなし）が最終候補**。両者はFPで同等、
感度でC1が優位。ただし C1 は blur を含まないため**照度劣化方向（暗く・ボケる）への
保険がない**。val は P設定（学習より鮮明）でのみ測定しており、この方向は測定できない。

→ 両者の長所を併せた **C3: sharpen p0.7/f4.0 + blur p0.3/σ0.6** をフル長で追加検証する
（短縮での順位が信頼できないと判明したため、推定ではなく直接測定する）。

### C3: 強sharpen + blur（フル長）— 組み合わせは負の相互作用

| 構成 | val後半 | 分離M | 181median | P-defect |
|---|---|---|---|---|
| C0: sharpen p0.3 + blur | **25.3%** | 1.251 | 1.597 | 1.253 |
| C1: sharpen p0.7/f4.0 | 29.9% | **1.514** | **2.063** | 1.364 |
| **C3: sharpen p0.7/f4.0 + blur** | 32.8% | 1.128 | 1.505 | 1.392 |
| C2: sharpen p0.5/f3.0 | 40.2% | 1.513 | 2.012 | 1.453 |

**C3は C0（FP）にも C1（感度）にも劣る**。「両方の勝ち筋を足す」は機能せず、
316のaugmentation実験で得た教訓（決定16: 2つの変更を同時に投入すると負の相互作用が起きる）
が再現した。**blur と強sharpen は負に干渉する**（分離M 1.514→1.128）。

### 最終候補の比較: C0 vs C1

| 指標 | C0（sharpen p0.3/f2.0 + blur p0.3/σ0.6） | C1（sharpen p0.7/f4.0・blurなし） | 判定 |
|---|---|---|---|
| val後半 NG率（FP） | **25.3%** | 29.9% | 差4.6pt < T=5.0 → **統計的に同等** |
| 分離マージン | 1.251 | **1.514** | C1優位（+21%） |
| 181実NG median | 1.597 | **2.063** | C1優位 |
| 181実NG **min** | 1.310 | **1.859** | **C1優位（閾値1.0からの余裕が31%→86%）** |
| P環境defect(n=1) | 1.253 | **1.364** | C1優位 |
| blur（劣化方向）の保険 | あり | **なし** | C0優位（ただしvalでは測定不能） |

**採用: C1（sharpen_p 0.7 / factor 1.0-4.0 / blur無効）**

理由:

1. **FPは統計的に同等**（差4.6pt < ノイズしきい値T=5.0pt）。C0のFP優位は有意でない
2. **感度はC1が全指標で明確に優位**。特に 181実NG の**最小スコアが 1.310 → 1.859** と
   大きく改善している（C0では最悪の不良が閾値のわずか31%上に留まる）
3. **視覚検査では見逃しが虚報より重い失敗**である（虚報は人の再確認で捕まるが、
   見逃しは出荷されてしまう）。FPが同等なら感度余裕の大きい方を採る
4. 本設定は**今後の全monochro再学習（他色番・他号機）に一律適用**され、個別に感度を
   検証できない。色番ごとの不良の強さのばらつきに対し、余裕の大きい方が安全
5. blur無しによる劣化方向の保険の欠如は、C3の結果から**blurと強sharpenが併用できない**ため
   トレードオフとして受け入れる。劣化方向は「保守後の撮像系ヘルスチェック」（別タスク）
   で運用的に検知する方が確実

**残存する限界**:
- フル長は各構成1 seed のみ。ノイズフロアは短縮学習で測定した値（1.1pt）を流用しており、
  フル長での実測はしていない。C0/C1のFP差を「同等」と扱う判断はこの前提に依存する
- P環境（新ドメイン）の実欠陥は1枚のみで、新ドメインでの感度は依然として検証できていない
